## What's inside

Twenty-five accessible components and a data table, built on React Aria and
styled with Tailwind CSS. Each one ships in four personalities: Sticker, Retro,
Comic and Arcade.

The docs are being written. Start with [Installation](/docs/installation), then
meet the [Personalities](/docs/personalities).
