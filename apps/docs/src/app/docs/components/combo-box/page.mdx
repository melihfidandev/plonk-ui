## Usage

```tsx
import { ComboBox, ComboBoxItem } from "plonk-ui";

export function City() {
  return (
    <ComboBox label="City" name="city">
      <ComboBoxItem id="istanbul">Istanbul</ComboBoxItem>
      <ComboBoxItem id="lisbon">Lisbon</ComboBoxItem>
    </ComboBox>
  );
}
```

Use a combo box when the list is long enough that typing is faster than
scrolling; for short lists, a [Select](/docs/components/select) is simpler.

### Options from data

`defaultItems` and a render function build the list from an array, and the
combo box filters it for you. `value` and `onChange` work with the option's
`id`. When nothing matches, the list says so with `emptyMessage`.

<Example name="combo-box/items" title="Combo Box · From data" />

Filtering matches the option's text, not its description. Matching and the
highlight follow the provider's `locale`, so in Turkish "iz" finds "İzmir".

### Custom values

`allowsCustomValue` keeps whatever was typed, even if no option matches. Read
it with `inputValue` and `onInputChange`.

<Example name="combo-box/custom" title="Combo Box · Custom values" />

## Personalities

The field lifts on focus like [Input](/docs/components/input), and the list
opens like a [Menu](/docs/components/menu#personalities). Matched letters are
marked with a highlighter stroke. The
[highlight hooks](/docs/components/menu#highlight-hooks) work here too.

## Accessibility

- The input keeps focus while the list is open; `↑` and `↓` move through the
  options and `Enter` picks one.
- `Esc` closes the list.
- Screen readers hear how many options match as you type.
- The label, description and error are linked to the input.
