## Usage

```tsx
import { Textarea } from "plonk-ui";

export function Feedback() {
  return <Textarea label="Message" name="message" rows={4} />;
}
```

`Textarea` renders a real `<textarea>` and passes every native prop to it:
`value` and `onChange`, `defaultValue`, `maxLength`, `rows`, `ref`. `className`
styles the outer wrapper. `description` and `error` work exactly like they do on
[Input](/docs/components/input#description-and-errors), and so does
[validation](/docs/components/input#forms-and-validation).

### Growing with the text

`autoResize` makes the field as tall as its content, up to 20rem, and then it
scrolls. It uses CSS `field-sizing`; in browsers without it, the field keeps a
fixed height that people can resize by hand.

### Character count

Control the value and put the count in `description`. It sits under the field
and is read along with the label. `maxLength` stops typing at the limit.

## Personalities

The field lifts on focus in Sticker, Comic and Retro, and lights a neon ring in
Arcade, just like Input. Errors stick on as a tilted tag and shake the field
once.

## Accessibility

- The label is a real `<label>` linked to the field. Without one, pass
  `aria-label`.
- `description` and `error` are linked with `aria-describedby`; `error` also
  sets `aria-invalid`.
- `Tab` moves out of the field; `Enter` adds a new line and never submits the
  form.
- Screen readers don't repeat the description while you type. For a limit
  that matters, also check it when the form is submitted.
