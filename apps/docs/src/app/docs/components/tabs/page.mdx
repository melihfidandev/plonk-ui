## Usage

```tsx
import { Tab, TabList, TabPanel, Tabs } from "plonk";

export function Project() {
  return (
    <Tabs>
      <TabList aria-label="Project">
        <Tab id="overview">Overview</Tab>
        <Tab id="settings">Settings</Tab>
      </TabList>
      <TabPanel id="overview">…</TabPanel>
      <TabPanel id="settings">…</TabPanel>
    </Tabs>
  );
}
```

Each `Tab` and its `TabPanel` share an `id`. Give the `TabList` an
`aria-label` that says what the tabs switch between. On narrow screens the bar
scrolls sideways instead of wrapping.

### Panels with content

Panels can hold anything, like forms. A tab can be disabled with `isDisabled`.

## Personalities

- **Sticker:** the indicator springs to the new tab and squashes like jelly;
  the panel rises in.
- **Retro:** the indicator jumps in steps.
- **Comic:** square panels, a slanted red indicator, and content that slides in
  like the next frame of a strip.
- **Arcade:** a neon indicator that blinks three times when it lands, and a
  panel that's wiped in from the top.

### Corner hook

Comic squares the tabs by setting `--plonk-tabs-radius`. It rounds the bar, the
tabs and the indicator together:

```css
.plonk-tablist {
  --plonk-tabs-radius: var(--plonk-radius-sm);
}
```

## Accessibility

- `Tab` moves into the tab list at the selected tab and then into the panel.
- `←` and `→` move between tabs (reversed in right-to-left languages), and
  `Home` and `End` jump to the ends.
- With `keyboardActivation="manual"`, arrows only move focus; `Enter` or
  `Space` selects.
- Tabs and panels are linked with `aria-controls` and `aria-labelledby`.
