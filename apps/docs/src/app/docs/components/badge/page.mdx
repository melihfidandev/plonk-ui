## Usage

```tsx
import { Badge } from "plonk";

export function Status() {
  return <Badge variant="success">Live</Badge>;
}
```

`Badge` is a `<span>` and isn't interactive. Put it next to the thing it
describes, inside a card header, a table cell or a list row.

### Variants

Each variant is a fill color from the personality's palette, with its matching
text color, so the pair always passes contrast.

<Example name="badge/variants" title="Badge · Variants" />

### Status dot

`dot` adds a small dot before the text, which helps a list of statuses scan at a
glance. The text still says the status; the color only supports it.

<Example name="badge/status" title="Badge · Status" />

## Personalities

Sticker and Retro keep the badge still. Comic makes it pop: it grows and tilts
under the pointer. Arcade blinks it three times. Both only react to a mouse, not
to touch. With reduced motion, Arcade's blinking stops and Comic's pop becomes a
short, plain ease.

## Accessibility

- A badge is plain text: screen readers read its content where it sits.
- Don't rely on color alone. "Failed" in red is clear; a red dot by itself
  isn't.
- The dot is hidden from screen readers.
