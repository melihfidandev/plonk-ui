First release. Neo-brutalist React components with four switchable personalities (Sticker, Retro, Comic, Arcade), each with its own look and motion language.

- 24 components: Button, Input, Textarea, Checkbox, Radio Group, Switch, Card, Badge, Avatar, Progress, Kbd, Dialog, Drawer, Popover, Tooltip, Menu, Select, Combo Box, Tabs, Accordion, Toast, Date Picker, Slider and Command Palette.
- A data table with sorting, filtering, column management, bulk selection and virtual scrolling.
- `PlonkProvider` with personalities, reduced motion, locale and theming through `--plonk-*` tokens.
- Accessible by default, built on React Aria; fonts ship with the package.
